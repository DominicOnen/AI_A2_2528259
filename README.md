## The problem

A potato cooperative in Musanze receives farm records in inconsistent spreadsheets. Its field officer needs an evidence-based tool to:

1. estimate harvest quantity (`yield_tons`) with **regression**,
2. flag farms at **high production risk** (`high_risk`, yield per hectare below the median) with **classification**,
3. group farms with similar field conditions with **clustering**.

Training and command-line prediction work locally (no internet). A FastAPI service is provided for later integration with a mobile app.

Valid request (`samples/valid.json`):

```json
{"rainfall_mm": 1000.0, "avg_temp_c": 18.5, "soil_moisture_pct": 55.0,
 "fertilizer_kg": 120.0, "field_size_ha": 1.8, "season": "A", "cooperative_support": 1}
```

Response (200): `yield_estimate_tons`, `risk_prediction`, `high_risk_probability`, `cluster`, `cluster_profile`, `verification_code` (`AI-A2-8259`), `disclaimer`.

Invalid request (`samples/invalid.json`) returns **422** with the bad fields, for example `rainfall_mm: Input should be less than or equal to 1400`, `field_size_ha: Field required`, `season: Input should be 'A' or 'B'`. Strict types: `"warm"` is not accepted as a temperature, and extra fields such as `yield_tons` are rejected.

## Design summary

- **Seed and size:** seed 8259, base rows 240 + (8259 mod 41) = 258, plus 3 duplicates = 261 rows.
- **Deliberate problems:** 13 missing `soil_moisture_pct`, 13 missing `fertilizer_kg`, 3 exact duplicates. The pipeline detects them (`artifacts/validation_report.json`), drops the duplicates, and imputes the missing numbers with the training-row median inside the model pipeline.
- **No leakage:** `yield_tons`, `high_risk` and yield per hectare are never inputs. One stratified split (`random_state=8259`, 80/20) is shared by all tasks. Imputer, scaler and encoder are fitted on training rows only.
- **Model choice:** by 5-fold cross-validation on training rows, picking the simplest model within one standard error of the best. Test rows are only used for the final scores.
- **Clustering:** K-means on the five scaled field-condition numbers, K = 2 to 6, K chosen by silhouette score. Targets are not used to form clusters.

## Known limitations

- Synthetic data: results show how the method behaves on made-up farms, not real ones.
- The synthetic conditions are independent and uniform, so clusters are weakly separated (silhouette about 0.18).
- The linear regression model cannot represent the V-shaped temperature effect exactly.
- Missing values are filled with the training median, which adds error for farms with missing soil moisture or fertilizer.
- With 258 rows and a 52-row test set, metrics move noticeably if the split changes.
- Scores of the random forest candidates can differ in the fourth decimal on other scikit-learn versions (checked with scikit-learn 1.6.1 and 1.9.1). The dataset fingerprint, the selected models and their metrics were identical on both.
- The service is a classroom prototype. A human must review every result. It must not replace an agronomist or decide access to finance, insurance or public services.
